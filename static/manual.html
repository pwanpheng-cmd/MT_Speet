1. เริ่มใช้งาน

เปิดใช้ได้ 2 แบบ คือ บนเครื่อง (ดับเบิลคลิก .bat) และ บนเว็บ (https://speed-vehicle-report.streamlit.app) หน้าจอเหมือนกัน เลือกหน้าจากเมนูด้านซ้ายทั้งหมด 7 หน้า:

หน้าใช้ทำอะไร
📋 รายการอุปกรณ์จัดการทะเบียนรถและอุปกรณ์หลัก (Master: หัวลาก / หางพ่วง / ตู้เย็น) ใช้เป็นฐานอ้างอิงสำหรับ ISO, KPI และแบบฟอร์มประจำเดือน
🚛 รายงานซ่อมรายคันอ่านไฟล์รายงานเบิกพัสดุ/สั่งซ่อมรายคัน (Crystal Reports) กระทบยอด 6 จุด และ Export เป็น Excel
🗂️ ฐานข้อมูลใบแจ้งซ่อมเก็บใบแจ้งซ่อม หัวลาก/หางพ่วง/ตู้เย็น แบบกันซ้ำ, คัดกรอง ISO (Yes/No), ดู KPI คัน/เดือน, Export M1/M2/M3
🖨️ พิมพ์รายงานประจำเดือนExport ชุดรายงาน KPI ประจำเดือน 13 ชีตตาม Template บริษัท (รวม Index และ Last PM), พิมพ์สรุป KPI และแบบฟอร์ม 1_หัวลาก / 2_หางพ่วง / 3_ซ่อมตู้ (Excel / PDF)
📏 เลขไมล์นำเข้าเลขไมล์รายคัน ตรวจสอบค่าผิดปกติ ดูเลขไมล์ล่าสุดและประวัติ
🛠️ PM Plan รายเดือนแผนเข้าศูนย์บริการ / เปลี่ยนถ่ายที่ลาน รายเดือน จากวันที่และเลขไมล์ PM ล่าสุด
📖 คู่มือการใช้งานหน้านี้ (เปิดแท็บใหม่ได้ที่ ?manual=1)

ล็อกอิน / สร้างผู้ใช้

  • ถ้ามีผู้ใช้แล้ว: กรอก ชื่อผู้ใช้ และ รหัสผ่าน แล้วกดเข้าสู่ระบบ
  • ใส่รหัสผิดหลายครั้ง ระบบจะล็อกชั่วคราว รอสักครู่แล้วลองใหม่
  • ครั้งแรกที่ยังไม่มีผู้ใช้ จะเห็นหน้า 🔐 ตั้งค่าผู้ใช้ครั้งแรก: กรอกชื่อผู้ใช้ (อังกฤษ/ตัวเลข) และรหัสผ่านอย่างน้อย 8 ตัว → ระบบสร้าง "บรรทัดผู้ใช้" (รหัสผ่านถูกเข้ารหัสแบบ PBKDF2-SHA256 แล้ว) → นำไปวางใน Secrets ตามคำแนะนำบนหน้าจอ
  • ออกจากระบบ: ปุ่ม ออกจากระบบ ใต้ชื่อผู้ใช้ในเมนูซ้าย

2. หน้า 📋 รายการอุปกรณ์ (Asset Master)

เก็บรายชื่อทะเบียนรถและอุปกรณ์หลักที่ใช้งานอยู่จริง แยก 3 กลุ่ม (หัวลาก · หางพ่วง · ตู้เย็น) ใช้เป็นฐานอ้างอิงสำหรับกำหนดคอลัมน์ ISO = Yes/No, คำนวณ KPI และพิมพ์แบบฟอร์มประจำเดือน

แท็บการใช้งาน
📋 รายชื่ออุปกรณ์ทั้งหมดกรองตามประเภท ค้นหาทะเบียน/เบอร์ตู้ เปิดดูรายการที่ปิดใช้งาน (ปลดระวาง) และกด ⬇️ Export Excel
➕ เพิ่ม / แก้ไข / วางรายชื่อชุดใหม่เพิ่มหรือปรับสถานะ (ใช้งาน / ปิดใช้งาน) รายคัน หรือคัดลอกรายชื่อหลายบรรทัดจาก Excel มาวางอัปเดตพร้อมกัน (ระบบสำรองฐานข้อมูลอัตโนมัติก่อนบันทึก)
📥 นำเข้าจากไฟล์ Excelอัปเดตทะเบียนจากไฟล์รายชื่ออุปกรณ์บริษัท (.xlsx) เลือกได้ว่าจะเพิ่มเฉพาะรายการในไฟล์ หรือปิดใช้งานรายการเดิมที่ไม่อยู่ในไฟล์ด้วย
ทุกครั้งที่เพิ่ม/แก้ไข/ปิดใช้งานทะเบียนหัวลากในหน้านี้ ระบบจะปรับคอลัมน์ ISO (Yes/No) ในตารางใบแจ้งซ่อมให้อัตโนมัติทันที

3. หน้า 🚛 รายงานซ่อมรายคัน

ขั้นตอน

  1. ① เลือกแหล่งข้อมูล ในเมนูซ้าย
    • โฟลเดอร์ในเครื่อง: กดปุ่ม 📁 เพื่อเลือกโฟลเดอร์รายงานรายคัน (เช่น D:\MT_Speed\Vehicle_Reports) หรือพิมพ์ path
    • อัปโหลดไฟล์: เลือกไฟล์ .xls/.xlsx หลายไฟล์ หรือบีบอัดทั้งโฟลเดอร์เป็น .zip แล้วอัปโหลดไฟล์เดียว
  2. เปิด ตัดไฟล์ซ้ำ ไว้ (ค่าเริ่มต้น) เพื่อข้ามไฟล์ที่เนื้อหาเหมือนกัน
  3. กด 🔍 อ่านข้อมูล
  4. ดูผลในแท็บด้านขวา แล้วกด 📤 Export Excel → บันทึกลงโฟลเดอร์ปลายทาง (บนเครื่อง) หรือกดดาวน์โหลด

ด้านบนแสดงการ์ด: ใบแจ้งซ่อมทั้งหมด, จำนวนแยก หัวลาก/หางพ่วง/ตู้เย็น และจำนวน รอตรวจ

① เลือกไฟล์ฐานข้อมูล (Browse Data File)

หน้า รายการอุปกรณ์, ฐานข้อมูลใบแจ้งซ่อม, พิมพ์รายงานประจำเดือน, เลขไมล์ และ PM Plan ใช้ไฟล์ฐานข้อมูลเดียวกัน Repair_Request_v2.sqlite — เลือกที่เมนูซ้ายหัวข้อ ① ไฟล์ฐานข้อมูล ครั้งเดียว ใช้ร่วมกันได้ทุกหน้า

บนเครื่อง (.bat)บนเว็บ
เลือกไฟล์กด 📁 แล้ว Browse ไฟล์ .sqlite (ค่าเริ่มต้น D:\MT_Speed\data\Repair_Request_v2.sqlite) หรือพิมพ์ pathกด Browse files แล้วเลือกไฟล์ .sqlite จากเครื่อง
บันทึกข้อมูลบันทึกลงไฟล์นั้นโดยตรง และสำรองอัตโนมัติก่อนนำเข้าทุกครั้งทำงานบน สำเนาชั่วคราว — เมื่อมีการเปลี่ยนแปลงจะขึ้นแถบเตือนสีเหลือง ให้กด ⬇️ ดาวน์โหลดฐานข้อมูล (บันทึกกลับเครื่อง) แล้ววางทับไฟล์เดิม
ปิดโปรแกรมข้อมูลอยู่ในไฟล์แล้วถ้าไม่ได้ดาวน์โหลดกลับ สิ่งที่นำเข้าบนเว็บจะหาย
บนเว็บ — วางไฟล์กลับเครื่อง: ปิดโปรแกรมบนเครื่องก่อน (ถ้าเปิดอยู่) → เปลี่ยนชื่อไฟล์เดิมเก็บไว้ (เช่น เติม _old) → นำไฟล์ที่ดาวน์โหลดมาวางเป็น D:\MT_Speed\data\Repair_Request_v2.sqlite
ใช้ฐานข้อมูลหลักชุดเดียว — อย่าแก้ไขพร้อมกันทั้งบนเว็บและบนเครื่อง

📥 นำเข้าไฟล์

เลือกไฟล์ .xlsx→ตรวจไฟล์ (ยังไม่บันทึก)→ดูผล ใหม่/อัปเดต/รอตรวจ→ติ๊กยืนยัน→นำเข้า
  1. อัปโหลดไฟล์ข้อมูลรถ (.xlsx) — รองรับทั้งไฟล์ที่มีชีต M1_ซ่อมรถ / M2_ซ่อมหาง / M3_ซ่อมตู้ และไฟล์รายเดือนที่มีชีต หัวลาก / หางพ่วง / ตู้เย็น
  2. กด 🔍 2) ตรวจไฟล์ (ยังไม่บันทึก) — ระบบอ่านและเทียบกับฐาน ยังไม่บันทึกอะไร
  3. ดูผลในแท็บย่อย: ใหม่ · อัปเดต (เก็บประวัติค่าเดิมไว้) · รอตรวจ (ไม่เข้าตารางหลัก) · รายการซ้ำในไฟล์ / หมายเหตุเวลา — กด Export ผลการตรวจ (Excel) เก็บไว้ตรวจได้
  4. ติ๊ก ตรวจผลด้านบนแล้ว ยืนยันนำเข้า แล้วกดปุ่มนำเข้า (ระบบอัปเดตคอลัมน์ ISO ให้อัตโนมัติหลังนำเข้า)
ก่อนนำเข้าทุกครั้ง ระบบสำรองฐานข้อมูลอัตโนมัติไว้ที่ data\backup\ · นำเข้าไฟล์เดิมซ้ำได้ ไม่เกิดข้อมูลซ้ำ

⚠️ รอตรวจ

รายการที่ระบบไม่นำเข้าเอง ต้องให้ DATA_OWNER ตัดสิน:

ประเภทความหมาย
ข้อมูลไม่ผ่านตรวจเช่น วันที่/ทะเบียน/ประเภทรถอ่านไม่ได้
ฟิลด์หลักเปลี่ยนเอกสารเดิมแต่ประเภทรถ วันที่แจ้งซ่อม หรือรหัสรถเปลี่ยนไป
ซ้ำในไฟล์ค่าต่างกันเลขที่เอกสารเดียวกันอยู่หลายแถวในไฟล์ แต่ค่าไม่เหมือนกัน
  1. อ่านเหตุผลและข้อมูลในกรอบ (ถ้ามีหลายแถว เลือก ใช้แถวที่ ต้องการ)
  2. กด นำเข้า หรือ ไม่นำเข้า — ระบบบันทึกชื่อผู้ตัดสินและเวลา

📋 ข้อมูลในฐาน

  • กรองตาม ประเภท, เดือน, สถานะ (Approved/Open/Cancel), ISO (Yes/No) และช่อง ค้นหา (ทะเบียน / เลขเอกสาร / รหัสพนักงาน)
  • กด Export ข้อมูลที่กรอง (Excel) — ไฟล์ที่ Export จะคัดเฉพาะ ISO = Yes เท่านั้น (ตัด ISO = No ออกอัตโนมัติ)
  • วันที่แสดงเป็นรูปแบบ วัน/เดือน/ปี (DD/MM/YYYY)

📤 Export ไปอัปเดตชีต M1/M2/M3

  1. ที่แท็บ ข้อมูลในฐาน กด 📤 สร้างไฟล์ M1/M2/M3
  2. บนเครื่องระบบบันทึกลง Export_File\ ให้อัตโนมัติ และกด ⬇️ ดาวน์โหลด อัปเดต_M1_M2_M3_วันที่_เวลา.xlsx ได้ทันที

6. หน้า 📏 เลขไมล์

นำเข้าเลขไมล์

  1. แท็บ 📥 นำเข้าไฟล์ → อัปโหลดไฟล์ .xlsx ที่มีคอลัมน์ Registration/ทะเบียน, Date/วันที่, km./เลขไมล์ (ไฟล์ที่ไม่มีหัวตารางแต่เรียงคอลัมน์แบบเดียวกันก็อ่านได้)
  2. กด 🔍 ตรวจไฟล์ (ยังไม่บันทึก) → ดูแท็บ ใหม่ และ รอตรวจ
  3. ติ๊ก ตรวจผลแล้ว ยืนยันนำเข้า → กด 💾 ยืนยันนำเข้าเลขไมล์

กันซ้ำด้วย ทะเบียน + วันที่ — นำเข้าไฟล์เดิมซ้ำได้ ไม่เกิดข้อมูลซ้ำ

รายการที่เข้า "รอตรวจ"

  • เลขไมล์ไม่ใช่ตัวเลข หรือน้อยกว่า 10 กม.
  • ทะเบียน+วันที่เดียวกันแต่เลขไมล์ต่างกัน
  • เลขไมล์ลดลงจากค่าครั้งก่อน

ที่แท็บ ⚠️ รอตรวจ: กรอกเลขไมล์ที่ถูกต้อง (ถ้ามี) แล้วกด นำเข้า หรือ ไม่นำเข้า

หมายเหตุที่ระบบแจ้งแต่ยังนำเข้า: เลขไมล์ต่ำกว่า 1,000 กม. หรือตั้งแต่ 1,000,000 กม. ขึ้นไป (มักเกิดจากหน้าปัดแบบ 6 หลักที่วนรอบ) — ควรตรวจกับหน้าปัดจริง

ดูข้อมูล

  • 📏 เลขไมล์ล่าสุด: ค่าล่าสุดของแต่ละทะเบียน ค้นหาและ Export ได้
  • 🕘 ประวัติ: เลขไมล์ทุกครั้งของทะเบียนที่ระบุ และรอบการนำเข้า

7. หน้า 🛠️ PM Plan รายเดือน

วางแผนเข้าศูนย์บริการ / เปลี่ยนถ่ายน้ำมันเครื่องของ หัวลาก รายเดือน จากวันที่และเลขไมล์ของ PM ครั้งล่าสุด และ กม./วันของแต่ละคัน ใช้ไฟล์ฐานข้อมูลเดียวกับหน้าอื่น (① ไฟล์ฐานข้อมูล ในเมนูซ้าย)

เกณฑ์

ประเภท PMนับจากรอบถัดไป
ศูนย์บริการใบสั่งซ่อม (W/O) ที่มีรายการน้ำมันเครื่อง หรือไส้กรองน้ำมันเครื่องทุก 20,000 กม. หรือ 6 เดือน
ลานใบเบิกพัสดุ (WX) ที่มีน้ำมันเครื่องทุก 30,000 กม. หรือ 6 เดือน
  • ครบกำหนด = ถึงเวลา 6 เดือน หรือ ถึงระยะ กม. อย่างใดอย่างหนึ่งก่อน
  • รอบถัดไป ใช้ระยะตามประเภท PM ครั้งล่าสุดของคันนั้น (ครั้งล่าสุดเข้าศูนย์ → 20,000 · ครั้งล่าสุดเปลี่ยนที่ลาน → 30,000)
  • กม./วัน = ระยะรวม ÷ จำนวนวัน จากเลขไมล์ทุกแหล่งใน 365 วันล่าสุด — ถ้าข้อมูลไม่พอหรือผิดปกติ ใช้ ค่ากลางของกองรถ
  • ระบบ ตัดเลขไมล์ที่ผิดปกติ ออกจากการคำนวณ (ลดลง, วิ่งเกิน 1,000 กม./วัน, ค่า < 1,000, สถานะ "ต้องตรวจ") และแจ้งไว้ในคอลัมน์ หมายเหตุ

ขั้นตอน

  1. เตรียมประวัติบริการ: หน้า 🚛 รายงานซ่อมรายคัน → อ่านข้อมูล → 📤 Export Excel ได้ไฟล์ Vehicle_Reports_วันที่_เวลา.xlsx
  2. หน้า PM Plan แท็บ 📥 นำเข้าประวัติบริการ → เลือกไฟล์นั้น → 🔍 ตรวจไฟล์ (ยังไม่บันทึก) → ติ๊กยืนยัน → 💾 ยืนยันนำเข้าประวัติบริการ
  3. นำเข้าไฟล์เลขไมล์ล่าสุดที่หน้า 📏 เลขไมล์ เพื่อให้ กม./วัน แม่นขึ้น
  4. แท็บ 📅 แผนรายเดือน → เลือก เดือนของแผน → ดูรายการ แล้วกด 📊 สร้างไฟล์ Export แผน PM → ⬇️ ดาวน์โหลด
ไม่มีประวัติ PM หมายถึงไม่พบ PM ในข้อมูลที่นำเข้า (ช่วงเวลาของไฟล์รายงาน) — ควรตรวจสอบหรือนัดตรวจเช็ค · วันครบกำหนดจากระยะ กม. เป็น ค่าประมาณ ควรยืนยันกับหน้าปัดจริงก่อนนัด

8. กฎของข้อมูล & ISO

  • เกณฑ์ ISO (Yes / No): ใบแจ้งซ่อม หัวลาก ที่ทะเบียนตรงกับรายการอุปกรณ์หลัก (Active Master) จะถูกกำหนดเป็น ISO = Yes ทะเบียนอื่นเป็น ISO = No · KPI คันต่อเดือน และไฟล์ Export ทุกเมนูจะคัดเฉพาะ ISO = Yes เท่านั้น (ตัด ISO = No ออกทั้งหมดอัตโนมัติ)
  • กันซ้ำ: ใบแจ้งซ่อมใช้ เลขที่เอกสาร เป็นคีย์ · เลขไมล์ใช้ ทะเบียน + วันที่
  • ไม่เดาข้อมูล: ค่าที่อ่านไม่ได้เก็บตามต้นฉบับ และแจ้งเป็นหมายเหตุ
  • ข้อมูลที่ไม่สอดคล้องกับตาราง ไม่เข้าฐานหลัก — ไปที่ "รอตรวจ" ให้ DATA_OWNER ตัดสิน
  • ทุกการเปลี่ยนแปลงมีร่องรอย: เก็บค่าเดิม ผู้นำเข้า ผู้ตัดสิน และเวลา
  • รหัสรถ: หัวลาก/หางพ่วง = 7 ตัวท้ายของ "ทะเบียน / เบอร์ตู้" · ตู้เย็น = ข้อความหลัง "/" ตัวสุดท้าย
  • ค่าเฉพาะองค์กร (แผน KPI รายเดือน, ค่าเฉลี่ยปีก่อน, หมายเหตุรถคืน) เก็บแยกไว้ในไฟล์ data\local_settings.json บนเครื่องเท่านั้น — ห้ามเผยแพร่ข้อมูลจริงภายนอก
