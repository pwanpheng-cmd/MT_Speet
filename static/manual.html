1. เริ่มใช้งาน

เปิดใช้ได้ 2 แบบ คือ บนเครื่อง (ดับเบิลคลิก .bat) และ บนเว็บ (https://speed-vehicle-report.streamlit.app) หน้าจอเหมือนกัน เลือกหน้าจากเมนูด้านซ้าย:

หน้าใช้ทำอะไร
🚛 รายงานซ่อมรายคันอ่านไฟล์รายงานเบิกพัสดุ/สั่งซ่อมรายคัน กระทบยอด และ Export เป็น Excel
🗂️ ฐานข้อมูลใบแจ้งซ่อมเก็บใบแจ้งซ่อม หัวลาก/หางพ่วง/ตู้เย็น แบบกันซ้ำ, ดู KPI, Export ไปอัปเดตชีต M1/M2/M3
📏 เลขไมล์นำเข้าเลขไมล์รายคัน ดูเลขไมล์ล่าสุดและประวัติ
🛠️ PM Plan รายเดือนแผนเข้าศูนย์บริการ / เปลี่ยนถ่ายที่ลาน รายเดือน จากวันที่และเลขไมล์ PM ล่าสุด
📖 คู่มือการใช้งานหน้านี้

เปิดโปรแกรมบนเครื่อง

  1. เปิดโฟลเดอร์ D:\MT_Speed
  2. ดับเบิลคลิก Run_Vehicle_Report_Web.bat
  3. หน้าต่างสีดำจะขึ้นมา — เปิดทิ้งไว้ ห้ามปิด แล้วเบราว์เซอร์จะเปิดที่ http://localhost:8501 เอง (ถ้าไม่เปิด ให้พิมพ์ที่อยู่นี้เอง)
  4. ใช้งานเสร็จ ปิดหน้าต่างสีดำเพื่อหยุดโปรแกรม
ครั้งแรกบนเครื่องใหม่ โปรแกรมจะติดตั้ง library ที่จำเป็นให้อัตโนมัติ อาจใช้เวลา 1–3 นาที ต้องมี Python 3.11 ขึ้นไปในเครื่อง

ล็อกอิน / สร้างผู้ใช้

  • ถ้ามีผู้ใช้แล้ว: กรอก ชื่อผู้ใช้ และ รหัสผ่าน แล้วกดเข้าสู่ระบบ
  • ใส่รหัสผิดหลายครั้ง ระบบจะล็อกชั่วคราว รอสักครู่แล้วลองใหม่
  • ครั้งแรกที่ยังไม่มีผู้ใช้ จะเห็นหน้า 🔐 ตั้งค่าผู้ใช้ครั้งแรก: กรอกชื่อผู้ใช้ (อังกฤษ/ตัวเลข) และรหัสผ่านอย่างน้อย 8 ตัว → ระบบสร้าง "บรรทัดผู้ใช้" (รหัสผ่านถูกเข้ารหัสแล้ว) → นำไปวางใน Secrets ตามคำแนะนำบนหน้าจอ
  • ออกจากระบบ: ปุ่ม ออกจากระบบ ใต้ชื่อผู้ใช้ในเมนูซ้าย

ใช้ ฐานข้อมูลหลักชุดเดียว (D:\MT_Speed\data\Repair_Request_v2.sqlite) — ถ้าคัดลอกไปหลายเครื่องหรือแก้บนเว็บแล้วไม่ดาวน์โหลดกลับ ข้อมูลจะไม่ตรงกัน · การเปิดฐานบนเว็บเป็นการส่งข้อมูลขึ้นเซิร์ฟเวอร์ชั่วคราว ใช้ตามที่ DATA_OWNER อนุญาต

2. หน้า 🚛 รายงานซ่อมรายคัน

ขั้นตอน

  1. ① เลือกแหล่งข้อมูล ในเมนูซ้าย
    • โฟลเดอร์ในเครื่อง: กดปุ่ม 📁 เพื่อเลือกโฟลเดอร์รายงานรายคัน (เช่น D:\MT_Speed\Vehicle_Reports) หรือพิมพ์ path
    • อัปโหลดไฟล์: เลือกไฟล์ .xls/.xlsx หลายไฟล์ หรือบีบอัดทั้งโฟลเดอร์เป็น .zip แล้วอัปโหลดไฟล์เดียว
  2. เปิด ตัดไฟล์ซ้ำ ไว้ (ค่าเริ่มต้น) เพื่อข้ามไฟล์ที่เนื้อหาเหมือนกัน
  3. กด 🔍 อ่านข้อมูล
  4. ดูผลในแท็บด้านขวา แล้วกด 📤 Export Excel → เลือกโฟลเดอร์ปลายทาง (บนเครื่อง) หรือกดดาวน์โหลด

3. หน้า 🗂️ ฐานข้อมูลใบแจ้งซ่อม

ด้านบนแสดงการ์ด: ใบแจ้งซ่อมทั้งหมด, จำนวนแยก หัวลาก/หางพ่วง/ตู้เย็น และจำนวน รอตรวจ

① เลือกไฟล์ฐานข้อมูล (Browse Data File)

ทั้งหน้า ฐานข้อมูลใบแจ้งซ่อม และ เลขไมล์ ใช้ไฟล์ฐานข้อมูลเดียวกัน Repair_Request_v2.sqlite — เลือกที่เมนูซ้ายหัวข้อ ① ไฟล์ฐานข้อมูล ครั้งเดียว ใช้ได้ทั้งสองหน้า

บนเครื่อง (.bat)บนเว็บ
เลือกไฟล์กด 📁 แล้ว Browse ไฟล์ .sqlite (ค่าเริ่มต้น D:\MT_Speed\data\Repair_Request_v2.sqlite) หรือพิมพ์ pathกด Browse files แล้วเลือกไฟล์ .sqlite จากเครื่อง (เช่น D:\MT_Speed\data)
บันทึกข้อมูลบันทึกลงไฟล์นั้นโดยตรง และสำรองอัตโนมัติก่อนนำเข้าทุกครั้งทำงานบน สำเนาชั่วคราว — เมื่อมีการเปลี่ยนแปลงจะขึ้นแถบเตือนสีเหลือง ให้กด ⬇️ ดาวน์โหลดฐานข้อมูล (บันทึกกลับเครื่อง) แล้ววางทับไฟล์เดิม
ปิดโปรแกรมข้อมูลอยู่ในไฟล์แล้วถ้าไม่ได้ดาวน์โหลดกลับ สิ่งที่นำเข้าบนเว็บจะหาย
บนเว็บ — วางไฟล์กลับเครื่อง: ปิดโปรแกรมบนเครื่องก่อน (ถ้าเปิดอยู่) → เปลี่ยนชื่อไฟล์เดิมเก็บไว้ (เช่น เติม _old) → นำไฟล์ที่ดาวน์โหลดมาวางเป็น D:\MT_Speed\data\Repair_Request_v2.sqlite
ใช้ฐานข้อมูลหลักชุดเดียว — อย่าแก้ไขพร้อมกันทั้งบนเว็บและบนเครื่อง

ไม่ได้เลือกไฟล์บนเว็บ: ระบบใช้ฐานว่างชั่วคราว เหมาะสำหรับตรวจไฟล์ก่อนนำเข้าจริง

📥 นำเข้าไฟล์

เลือกไฟล์ .xlsx→ตรวจไฟล์ (ยังไม่บันทึก)→ดูผล ใหม่/อัปเดต/รอตรวจ→ติ๊กยืนยัน→นำเข้า
  1. อัปโหลดไฟล์ข้อมูลรถ (.xlsx) — รองรับทั้งไฟล์ที่มีชีต M1_ซ่อมรถ / M2_ซ่อมหาง / M3_ซ่อมตู้ และไฟล์รายเดือนที่มีชีต หัวลาก / หางพ่วง / ตู้เย็น
  2. กด 🔍 2) ตรวจไฟล์ (ยังไม่บันทึก) — ระบบอ่านและเทียบกับฐาน ยังไม่บันทึกอะไร
  3. ดูผลในแท็บย่อย:
    • ใหม่ — เลขที่เอกสารที่ยังไม่มีในฐาน
    • อัปเดต — เอกสารเดิมที่สถานะ/เวลา/พนักงาน ฯลฯ เปลี่ยน (เก็บประวัติค่าเดิมไว้)
    • รอตรวจ — ข้อมูลไม่สอดคล้อง จะไม่เข้าตารางหลัก
    • รายการซ้ำในไฟล์ / หมายเหตุเวลา (เวลาที่อ่านไม่ได้จะเก็บค่าตามต้นฉบับ ไม่เดา)
    กด Export ผลการตรวจ (Excel) เพื่อเก็บผลไว้ตรวจได้
  4. ติ๊ก ตรวจผลด้านบนแล้ว ยืนยันนำเข้า แล้วกดปุ่มนำเข้า (ครั้งแรกปุ่มจะชื่อ สร้างฐานข้อมูลหลัก (ชุดแรก))
ก่อนนำเข้าทุกครั้ง ระบบสำรองฐานข้อมูลอัตโนมัติไว้ที่ data\backup\ · นำเข้าไฟล์เดิมซ้ำได้ ไม่เกิดข้อมูลซ้ำ

⚠️ รอตรวจ

รายการที่ระบบไม่นำเข้าเอง ต้องให้ DATA_OWNER ตัดสิน:

ประเภทความหมาย
ข้อมูลไม่ผ่านตรวจเช่น วันที่/ทะเบียน/ประเภทรถอ่านไม่ได้
ฟิลด์หลักเปลี่ยนเอกสารเดิมแต่ประเภทรถ วันที่แจ้งซ่อม หรือรหัสรถเปลี่ยนไป
ซ้ำในไฟล์ค่าต่างกันเลขที่เอกสารเดียวกันอยู่หลายแถวในไฟล์ แต่ค่าไม่เหมือนกัน
  1. อ่านเหตุผลและข้อมูลในกรอบ
  2. ถ้ามีหลายแถว เลือก ใช้แถวที่ ต้องการ
  3. กด นำเข้า (ใช้ค่าตามไฟล์) หรือ ไม่นำเข้า — ระบบบันทึกชื่อผู้ตัดสินและเวลา

📋 ข้อมูลในฐาน

  • กรองตาม ประเภท, เดือน, สถานะ (Approved/Open/Cancel) และช่อง ค้นหา (ทะเบียน / เลขเอกสาร / รหัสพนักงาน) แล้วกด Export ข้อมูลที่กรอง (Excel)
  • วันที่แสดงเป็นรูปแบบ วัน/เดือน/ปี (DD/MM/YYYY)

📤 Export ไปอัปเดตชีต M1/M2/M3

  1. ที่แท็บ ข้อมูลในฐาน กด 📤 สร้างไฟล์ M1/M2/M3 (ใช้เวลาประมาณ 10–30 วินาที)
  2. กด ⬇️ ดาวน์โหลด อัปเดต_M1_M2_M3_วันที่_เวลา.xlsx
  3. ไฟล์มี 4 ชีต: M1_ซ่อมรถ, M2_ซ่อมหาง, M3_ซ่อมตู้ (หัวตาราง สูตร และฟอนต์เหมือนไฟล์หลัก) และ ข้อมูลการ Export (จำนวนแถว เวลา และรายการรอตรวจที่ยังไม่รวม)

วิธีวางลงไฟล์หลัก

  1. สำรองไฟล์หลัก ทะเบียนรถและรายการซ่อม … iso.xlsx ก่อน
  2. ในแต่ละชีต M1/M2/M3 ของไฟล์หลัก ลบข้อมูลตั้งแต่ แถว 3 ลงไป
  3. คัดลอกคอลัมน์ B ถึงคอลัมน์สุดท้าย (แถว 3 ลงไป) จากไฟล์ Export → วางที่ B3 ของชีตชื่อเดียวกัน
  4. ตรวจว่าจำนวนแถวตรงกับชีต "ข้อมูลการ Export" และคอลัมน์ ISO คำนวณได้
คอลัมน์ ISO (M1 คอลัมน์ M) ใช้สูตร XLOOKUP ไปที่ชีต pm ซึ่งอยู่ในไฟล์หลักเท่านั้น — ในไฟล์ Export จะแสดง error/ว่าง เป็นเรื่องปกติ จะคำนวณได้เมื่อวางลงไฟล์หลัก
รายการที่ยัง รอตรวจ จะไม่อยู่ในไฟล์ Export จนกว่าจะตัดสิน "นำเข้า"

📊 KPI คัน/เดือน และ 🕘 ประวัติ

  • KPI: จำนวนคัน/ตู้ที่แจ้งซ่อม (ไม่นับซ้ำ) และจำนวนใบแจ้งซ่อม แยกเดือน × ประเภท
    กด 📊 สร้างไฟล์ Export KPI → ⬇️ ดาวน์โหลด ได้ไฟล์ที่มีชีต คันต่อเดือน, ใบแจ้งซ่อมต่อเดือน (มีแถวรวม) และ รายละเอียดการซ่อม M1_ซ่อมรถ / M2_ซ่อมหาง / M3_ซ่อมตู้ แยกชีต (มีตัวกรองหัวตาราง, วันที่ DD/MM/YYYY) พร้อมชีต "ข้อมูลการ Export"
  • ประวัติ: รายการนำเข้าแต่ละรอบ (ไฟล์ ผู้นำเข้า จำนวนเพิ่ม/อัปเดต/รอตรวจ ไฟล์สำรอง), ประวัติการเปลี่ยนแปลงข้อมูล (ค่าเดิม → ค่าใหม่) และดาวน์โหลดไฟล์ฐานข้อมูล (.sqlite)

4. หน้า 📏 เลขไมล์

นำเข้าเลขไมล์

  1. แท็บ 📥 นำเข้าไฟล์ → อัปโหลดไฟล์ .xlsx ที่มีคอลัมน์ Registration/ทะเบียน, Date/วันที่, km./เลขไมล์ (ไฟล์ที่ไม่มีหัวตารางแต่เรียงคอลัมน์แบบเดียวกันก็อ่านได้)
  2. กด 🔍 ตรวจไฟล์ (ยังไม่บันทึก) → ดูแท็บ ใหม่ และ รอตรวจ
  3. ติ๊ก ตรวจผลแล้ว ยืนยันนำเข้า → กด 💾 ยืนยันนำเข้าเลขไมล์

กันซ้ำด้วย ทะเบียน + วันที่ — นำเข้าไฟล์เดิมซ้ำได้ ไม่เกิดข้อมูลซ้ำ

รายการที่เข้า "รอตรวจ"

  • เลขไมล์ไม่ใช่ตัวเลข หรือน้อยกว่า 10 กม.
  • ทะเบียน+วันที่เดียวกันแต่เลขไมล์ต่างกัน
  • เลขไมล์ลดลงจากค่าครั้งก่อน

ที่แท็บ ⚠️ รอตรวจ: กรอกเลขไมล์ที่ถูกต้อง (ถ้ามี) แล้วกด นำเข้า หรือ ไม่นำเข้า — ถ้าค่าในไฟล์ไม่ใช่ตัวเลข ต้องกรอกเลขไมล์ก่อนจึงนำเข้าได้

หมายเหตุที่ระบบแจ้งแต่ยังนำเข้า: เลขไมล์ต่ำกว่า 1,000 กม. หรือตั้งแต่ 1,000,000 กม. ขึ้นไป (มักเกิดจากหน้าปัดแบบ 6 หลักที่วนรอบ) — ควรตรวจกับหน้าปัดจริง

ดูข้อมูล

  • 📏 เลขไมล์ล่าสุด: ค่าล่าสุดของแต่ละทะเบียน ค้นหาทะเบียนได้ Export ได้
  • 🕘 ประวัติ: เลขไมล์ทุกครั้งของทะเบียนที่ระบุ และรอบการนำเข้า

5. หน้า 🛠️ PM Plan รายเดือน

วางแผนเข้าศูนย์บริการ / เปลี่ยนถ่ายน้ำมันเครื่องของ หัวลาก รายเดือน จากวันที่และเลขไมล์ของ PM ครั้งล่าสุด และ กม./วันของแต่ละคัน ใช้ไฟล์ฐานข้อมูลเดียวกับหน้าอื่น (① ไฟล์ฐานข้อมูล ในเมนูซ้าย)

เกณฑ์

ประเภท PMนับจากรอบถัดไป
ศูนย์บริการใบสั่งซ่อม (W/O) ที่มีรายการน้ำมันเครื่อง หรือไส้กรองน้ำมันเครื่องทุก 20,000 กม. หรือ 6 เดือน
ลานใบเบิกพัสดุ (WX) ที่มีน้ำมันเครื่องทุก 30,000 กม. หรือ 6 เดือน
  • ครบกำหนด = ถึงเวลา 6 เดือน หรือ ถึงระยะ กม. อย่างใดอย่างหนึ่งก่อน
  • รอบถัดไป ใช้ระยะตามประเภท PM ครั้งล่าสุดของคันนั้น (ครั้งล่าสุดเข้าศูนย์ → 20,000 · ครั้งล่าสุดเปลี่ยนที่ลาน → 30,000)
  • กม./วัน = ระยะรวม ÷ จำนวนวัน จากเลขไมล์ทุกแหล่ง (ไฟล์เลขไมล์ + เลขไมล์ในใบสั่งซ่อม/ใบเบิก) ใน 365 วันล่าสุด — ถ้าข้อมูลไม่พอหรือผิดปกติ ใช้ ค่ากลางของกองรถ
  • วิ่งแล้วตั้งแต่ PM = เลขไมล์ล่าสุด − เลขไมล์ตอน PM (+ ประมาณจาก กม./วัน ถึงวันนี้) ; ถ้า PM ไม่มีเลขไมล์ที่ใช้ได้ = กม./วัน × จำนวนวัน
  • ระบบ ตัดเลขไมล์ที่ผิดปกติ ออกจากการคำนวณ (ลดลง, วิ่งเกิน 1,000 กม./วัน, ค่า 1 หรือ < 1,000, สถานะ "ต้องตรวจ") และบอกไว้ในคอลัมน์ หมายเหตุ — ดูรายละเอียดได้ที่แท็บประวัติรายคัน

ขั้นตอน

  1. เตรียมประวัติบริการ: หน้า 🚛 รายงานซ่อมรายคัน → อ่านข้อมูล → 📤 Export Excel ได้ไฟล์ Vehicle_Reports_วันที่_เวลา.xlsx
  2. หน้า PM Plan แท็บ 📥 นำเข้าประวัติบริการ → เลือกไฟล์นั้น → 🔍 ตรวจไฟล์ (ยังไม่บันทึก) → ดูจำนวนใหม่/อัปเดต และตัวอย่างเอกสารที่นับเป็น PM → ติ๊กยืนยัน → 💾 ยืนยันนำเข้าประวัติบริการ (กันซ้ำด้วยเลขที่เอกสาร นำเข้าไฟล์ใหม่ทับได้)
  3. นำเข้าไฟล์เลขไมล์ล่าสุดที่หน้า 📏 เลขไมล์ เพื่อให้ กม./วัน แม่นขึ้น
  4. แท็บ 📅 แผนรายเดือน → เลือก เดือนของแผน → ดูรายการ แล้วกด 📊 สร้างไฟล์ Export แผน PM → ⬇️ ดาวน์โหลด

แท็บในหน้า

แท็บเนื้อหา
📅 แผนรายเดือนคันที่ ครบกำหนดในเดือน, เกินกำหนด (ค้าง) จากเดือนก่อน และ ไม่มีประวัติ PM (เปิด/ปิดได้) · การ์ดสรุป · Export (ชีตแผน, สถานะทุกคัน, เกณฑ์การคำนวณ) · ⚙️ ปรับเกณฑ์ชั่วคราวได้
🚛 สถานะรายคันทุกคัน พร้อมสถานะเทียบกับวันนี้: เกินกำหนด / ครบกำหนดเดือนนี้ / ยังไม่ถึง / ไม่มีประวัติ PM
📥 นำเข้าประวัติบริการนำเข้าไฟล์ Export รายงานซ่อมรายคัน และประวัติการนำเข้า
🔎 ประวัติรายคันประวัติ PM และเลขไมล์ทุกแหล่งของคันที่เลือก พร้อมบอกว่าค่าไหน "ใช้คำนวณ" หรือ "ตัดออก" และกราฟเลขไมล์
ไม่มีประวัติ PM หมายถึงไม่พบ PM ในข้อมูลที่นำเข้า (ช่วงเวลาของไฟล์รายงาน) — ควรตรวจสอบหรือนัดตรวจเช็ค · วันครบกำหนดจากระยะ กม. เป็น ค่าประมาณ ควรยืนยันกับหน้าปัดจริงก่อนนัด

6. กฎของข้อมูล

  • กันซ้ำ: ใบแจ้งซ่อมใช้ เลขที่เอกสาร เป็นคีย์ · เลขไมล์ใช้ ทะเบียน + วันที่
  • ไม่เดาข้อมูล: ค่าที่อ่านไม่ได้เก็บตามต้นฉบับ และแจ้งเป็นหมายเหตุ
  • ข้อมูลที่ไม่สอดคล้องกับตาราง ไม่เข้าฐานหลัก — ไปที่ "รอตรวจ" ให้ DATA_OWNER ตัดสิน
  • ทุกการเปลี่ยนแปลงมีร่องรอย: เก็บค่าเดิม ผู้นำเข้า ผู้ตัดสิน และเวลา
  • รหัสรถ: หัวลาก/หางพ่วง = 7 ตัวท้ายของ "ทะเบียน / เบอร์ตู้" · ตู้เย็น = ข้อความหลัง "/" ตัวสุดท้าย
  • ห้ามนำข้อมูลออกไปเผยแพร่ภายนอก
